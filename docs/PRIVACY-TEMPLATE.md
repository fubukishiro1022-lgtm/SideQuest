# Privacy notice (template)

This is a plain-language template that matches how the app works today. It is **not legal advice**. Adapt it, and have it reviewed, before you rely on it.

**What we store.** Player names, star levels, match results, club settings, and a club name with a salted password hash.

**Where.** Only in the browser on the device being used. The app does not send data to any server, analytics service or third party. If you clear browser data, it is deleted.

**Who can see it.** Anyone who can use that browser profile on that device.

**Why.** To run open-play sessions: matching, scores, results and history.

**How long.** Until you delete it. History keeps the last 25 sessions.

**Your choices.** Remove a player on the Players page. Delete everything for a club from Help → Delete all data. Download a copy of your data from History → Download backup.

**Organizers.** If you run sessions for other people, you decide whose names are added. Only add people who know their name is used, and tell them how to ask for it to be removed.

**If this changes.** If you add accounts, a server, analytics or cookies, update this notice first.
